# WSCtrial – WorldSkills aplikacija

WSCtrial je WinForms desktop aplikacija razvijena u C# (.NET Framework) koja simulira osnovne procese natjecanja tipa WorldSkills.

## Značajke
- Prijava i registracija korisnika
- Više korisničkih uloga (Natjecatelj, Sudac, Voditelj)
- Rad s bazom podataka putem DataSeta
- Jednostavno i pregledno grafičko sučelje

## Tehnologije
- C#
- .NET Framework (4.6.1 / 4.8)
- Windows Forms
- Visual Studio

## Namjena
Projekt je edukativnog karaktera i služi kao primjer WinForms aplikacije s autentikacijom i podjelom uloga.
